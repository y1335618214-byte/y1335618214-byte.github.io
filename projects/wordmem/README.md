# WordMem · 好好背单词

WordMem 把六批手写词表做成了可以翻面的复习卡片。你可以看英文回忆中文，也可以看中文想英文。翻面核对并标记掌握程度后，下次可以挑出没记牢的词再练。六批词表共 421 条，跨批去重后有 414 个词条。

[打开 WordMem](https://y1335618214-byte.github.io/projects/wordmem/)

## 使用与备份

选一批词开始练习，可以按顺序学，也可以打乱顺序。学习进度保存在当前浏览器。换设备前，在「手机与备份」导出学习备份，再到新设备上导入。

## 离线与本地运行

第一次联网打开网站后，进入「手机与备份」，等离线包就绪即可离线复习。在本目录运行 `python3 -m http.server 8000`，再访问 `http://localhost:8000/`，即可在本机试用。
