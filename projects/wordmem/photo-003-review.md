# 第三批手写词表：纵向校对
共 59 词条，四列分别 14、15、14、16 个。按每列从上到下、列从左到右录入。

## 校对重点
- 手写 frajile → fragile：易碎的、脆弱的。
- 手写 induse → induce：引起、诱使。
- 手写 aggession → aggression：侵略、攻击行为，补 r。
- co-ordinate 是有效写法，统一为 coordinate，不计作拼写错误。
- 第四列首词按划改后的 retain 录入，划掉的草稿不另建词条。
- dynamics：动力学、动态关系、作用机制；不直接等同于 motivation（动力、动机）。
- innate：天生的、固有的；去掉“真诚的”。
- faculty：全体教员、院系或能力，不笼统标为全体雇员。
- microbe 是微生物，不局限于细菌；clue 是线索，不是一般的解释。
- addictive 是“使人上瘾的”，addicted 才是“已上瘾的”。
- 批内无重复；与前两批重合：无。minor 与示例词表重合，仍在本批独立记录进度。
