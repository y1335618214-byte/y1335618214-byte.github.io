# 手写词表第 1 批：纵向整理

顺序：每列自上而下，再从左列到右列。共 58 词条，批内无重复。

## 校对重点

- 第 2 列 notwithstanding：照片中的中间字母看起来有遗漏，已规范为 notwithstanding。
- 第 2 列 whereas：以“然而／而／却”为主要释义，不等同于尽管。
- 第 2 列 unnatural：“肥料”不属于本词词义，已去除。
- 第 3 列 evitable：有效但少见，意为可避免的；保留原词，不改为 inevitable。
- 第 3 列 make up：保留原词；弥补损失常用 make up for，补足差额可用 make up the difference。
- 第 4 列 criteria：复数，单数 criterion。
- 第 4 列 provision：本词主要按名词记“提供／供应”，动词通常用 provide。
- 与示例词表重合 comprehend、initiate；保留在本批独立学习，不继承示例自评。

词典核对：[evitable](https://www.collinsdictionary.com/us/dictionary/english/evitable)、[notwithstanding](https://dictionary.cambridge.org/us/dictionary/english/notwithstanding)、[whereas 的对比用法](https://dictionaryblog.cambridge.org/2022/11/16/whereas-despite-and-nevertheless-ways-to-link-ideas-1/)。
